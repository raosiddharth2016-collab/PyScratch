PyCode — Python to Scratch (.sb3) Compiler

Write Scratch-compatible Python code below and click compile to download a Scratch 3.0 project file.


How to Run Your Compiled File

  1. Click Compile & Download .sb3 above to download scratch_project.sb3.
  2. Open scratch.mit.edu/projects/editor.
  3. Click File → Load from your computer and choose scratch_project.sb3.
  4. Click the Green Flag to run your blocks!

Restrictions & What Does NOT Work

Note: PyCode translates Python syntax directly into Scratch blocks. Standard Python modules and object-oriented features are not supported.
  • No External Modules: import math, import random, or import time do not work. Use wait(1) instead.
  • No Classes or OOP: Defining class objects or self properties is not supported.
  • Basic Math Only: Standard operators (+, -, *, /) and comparisons (==, <, >) work. Advanced functions like math.cos() or math.sqrt() are not supported.

Supported Commands Cheatsheet

  • Motion: move(10), turn_right(90), turn_left(90)
  • Looks & Control: print("Hello"), wait(1), if / else, while, for i in range(5):
  • Pen Extension: pen.clear(), pen.down(), pen.up(), pen.set_color("#FF3366"), pen.set_size(4)
  • Text to Speech: tts.speak("Hello")
  • Music Extension: music.play_note(60, 0.25)
